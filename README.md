# Think Before You Click: Phishing, Scams & Social Engineering

**Presenter:** Nikhil Jamkar

## Project overview
This project generates a 10-slide PowerPoint presentation that introduces phishing, common online scams, social engineering, warning signs, protective habits, and steps to take after a suspicious click.

## Files
- `generate_presentation.py` — Python source code that creates the presentation.
- `requirements.txt` — Python dependency list.
- `project_report.md` — Project report with objectives, scope, approach, and conclusion.
- `README.md` — Setup and usage instructions.

## Requirements
- Python 3.9 or newer
- `python-pptx`

## Setup and run
1. Install Python if it is not already installed.
2. Open a terminal in this folder.
3. Install the dependency:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the generator:

   ```bash
   python generate_presentation.py
   ```

5. The PowerPoint file `Think_Before_You_Click_Nikhil_Jamkar.pptx` will be created in the current folder.

## Notes
- The generated deck is designed for a classroom presentation.
- Review contact numbers and reporting guidance against current official sources before presenting.
- This is an awareness/educational project, not a security scanning application.
